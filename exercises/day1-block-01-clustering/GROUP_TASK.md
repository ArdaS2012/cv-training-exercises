# Build, compare, challenge

30 minutes in pairs; swap who edits.

1. Implement point assignment and centroid updates. Compare 1 → 6 updates with scikit-learn, using the supplied identical start.
2. Configure and fit K-Means, single-linkage hierarchy and DBSCAN on the same curved points. Hold K=2, scaling and min_samples=5 fixed; vary eps .3 → .6.
3. Switch to noisy points and locate a grouping failure. Cluster IDs are not classes.

Keep your code and plots for the trainer's solution walkthrough. No written prediction, observation log or group presentation required. [Input/output and API reference](TASK_API.md).
