# Build vision prompt scoring

30 minutes in pairs; swap who edits.

Implement cosine scores, stable softmax and normalized-to-pixel spatial prompts. Compare your CLIP scores with the library, then move one SAM point or add a negative point while image and text remain fixed.

Keep your code and computed results. The trainer presents the completed solution afterward. No written prediction or observation fields; trial download is optional. [Inputs and APIs](TASK_API.md).
