# Teach a digit reader

30 minutes in pairs; swap who edits.

Implement the seven-stage training pipeline: data rows, initialization, forward pass, loss, update, training and validation. Compare 0/80 updates at rate.5, then80 at2.0; inspect the same held-out image and loss curves. Keep the test split untouched.

Keep working code and plots for the trainer’s solution walkthrough. No written prediction, observation log or group presentation required. Trial download is optional.
