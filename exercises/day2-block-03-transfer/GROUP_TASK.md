# Implement a transfer audit

30 minutes in pairs; swap who edits.

Implement the two-class head that both routes train through, configure frozen/trainable parameters and measure actual before/after deltas. Compare frozen features with a last-block fine-tune under an equal budget (150 Adam steps each). Stretch: probe both routes on inverted digits (domain shift).

Keep your code and plots; the trainer presents the completed solution. No written prediction, observation log or group presentation. [Input/output and APIs](TASK_API.md).
