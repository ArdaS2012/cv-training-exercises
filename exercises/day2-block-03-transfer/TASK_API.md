`model.named_parameters()` yields `(str,torch.nn.Parameter)` pairs; exact six names: conv1.weight (8,1,3,3), conv1.bias (8,), conv2.weight (12,8,3,3), conv2.bias (12,), head.weight (2,48), head.bias (2,). `parameter.requires_grad_(enabled)` mutates gradient eligibility in place and returns the parameter. Return the same supplied model. No weight values are edited by this function. `name.split('.')[0]` gives the owning group.

Snapshots passed to parameter_deltas have these same six names/shapes and independent detached CPU tensor storage. Return all six maximum-absolute differences as Python floats; `abs()`/`max()` reduce magnitudes, `float(scalar_tensor)` reads a scalar. Preserve snapshots. Zero delta means no entry changed; nonzero means at least one changed.

`day2.adapt(2,groups,configure=your_function,audit=your_function)` first fits a fresh parity head for 35 updates on cached frozen features, then runs your configure function on a copy for 12 selective updates. It calls your audit on actual before/after snapshots. Groups is {'conv1':False,'conv2':True,'head':True}; the prepared optimizer enforces this requested experiment. None from either callback leaves output waiting, never a reference-solution fallback. Returned report has routes (route:str, trainable_parameters:int, validation_loss:float≥0, validation_accuracy:float[0,1]), fine_tune_max_absolute_delta (your six-name dictionary), trainable_names:list[str], validation_comparison records (image_id:int,target/head_only/last_block:int0/1,changed:bool), budgets (head_epochs:int35,fine_tune_epochs:int12), validation_predictions_by_route, validation_targets, validation_ids, source_target_disjoint:bool and task/seed metadata. Source-pretraining and target-example IDs are disjoint. The selective route has additional updates, so it is not an equal-total-budget unfreezing-only comparison.
