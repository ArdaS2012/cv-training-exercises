# Day 3 model and data provenance

The semantic and center U-Nets are authored 3→8/16→8 small CPU models trained on 300 seeded geometric scenes for350 steps. Their skip concatenation is real. Held-out scenes use seeds400,401,406; seed406 supplies an observed touching-object failure. The fourth input is the exact authored Day1 scene, retained as a domain comparison. Instance identities use learned center peaks and supplied watershed; this is not an implementation of Mask R-CNN. Shape scenes/checkpoints: CC0-1.0. [Detailed provenance](teaching-provenance.json).

The shared pair encoder64→48→8 was trained for600 steps on sklearn digits excluding the entire300-row target set. `pairs.npz` records original sample IDs for24 held-out pairs. Dataset terms/attribution: [scikit-learn digits](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_digits.html), UCI Optical Recognition of Handwritten Digits. Teaching checkpoint: CC0-1.0. No natural-photo matching guarantee.

`model-manifest.json` pins official CLIP ViT-B/32 revision3d74acf9a28c67741b2f4f2ea7635f0aaf6f0268 and SAM ViT-B revision70c1a07f894ebb5b307fd9eaaee97b9dfc16068f. [CLIP model card](https://huggingface.co/openai/clip-vit-base-patch32), [official MIT license](https://github.com/openai/CLIP/blob/main/LICENSE); [SAM card](https://huggingface.co/facebook/sam-vit-base), Apache-2.0. Source photos are retained from the official Ultralytics example assets with their existing Day2 attribution, [Day2 provenance](../day2/README.md). Cached image encodings and `prompt-baselines.json` were computed with these exact checkpoints and Transformers4.57.1, CPU, original-image spatial coordinates. They are not fabricated predictions.

Block4 online preflight downloads the specified CLIP binary and SAM safetensors plus processors/tokenizers into ignored `.cache/day3/hub/`, approximately1GB. The student ZIP contains small checkpoints and matching image encodings, not the official large model weights. Run online before class, then verify `uv run --offline --locked python start.py --day 3 --block 4 --offline-assets --check`. Text inference and SAM prompt decoding execute locally on CPU with those cached weights; no GPU/API key. Cached encodings reduce latency while preserving genuine model computation. No package registry or model download is attempted by the offline path.

Block5 reuses the authored Day2 tiny CNN and its disjoint180/60/60 target split. A controlled brightness transform demonstrates one defined domain shift. Test rows stay unused. The exported inference ZIP contains model weights, preprocessing/labels/revision configuration and documentation; local POST verification closes its ephemeral loopback server after the request. Hub/hosted routes are taught in the presenter guide and require a compatible runtime; this exercise provisions no paid endpoint.
